Agentic RAG · LangChain · Pinecone

Ask the LangChain docs. Get answers with sources.

An AI agent that searches the official LangChain documentation, pulls the most relevant chunks from a Pinecone index, and answers with citations. When the docs don't cover something, it says so instead of guessing.

How it works

Ingestion · ingestion.py

  1. Crawl the docs with Tavily.
  2. Convert each page to a LangChain Document with its URL.
  3. Chunk into ~4,000-character pieces with 200 characters of overlap.
  4. Embed and store in Pinecone, in batches written concurrently with asyncio.

Answering · core.py

  1. The agent reads the question and decides what to search for.
  2. It calls retrieve_context, a similarity search over Pinecone, as many times as it needs.
  3. It answers only from the retrieved chunks and cites each page.
  4. The Streamlit UI streams every step as it happens.

Stack

Run it locally

Needs Python 3.11+, uv, and OpenAI, Pinecone and Tavily API keys in .env.

git clone https://github.com/hudezz/documentation-assistant
cd documentation-assistant
uv sync

uv run ingestion.py                    # crawl the docs and fill Pinecone
uv run streamlit run frontend/app.py   # open the app

Full setup, including creating the Pinecone index, is in the README.
